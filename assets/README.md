# Assets Directory

## Icon Required

Please add an icon file named `icon.ico` to this directory.

### Requirements:
- **Format**: .ico (Windows Icon)
- **Sizes**: Multiple sizes embedded (16x16, 32x32, 48x48, 64x64, 128x128, 256x256)
- **Recommended tool**: Use an online converter like:
  - https://convertio.co/png-ico/
  - https://icoconvert.com/

### Usage:
This icon will be used for:
- Application window icon
- System tray icon
- Installer icon
- Desktop shortcut icon
- Start menu shortcut icon

### Creating an Icon:
1. Create or find a PNG image (preferably 512x512 or larger)
2. Convert to .ico with multiple sizes using one of the tools above
3. Save as `icon.ico` in this directory

**Note**: Until you add an icon, the build process may use a default Electron icon.
