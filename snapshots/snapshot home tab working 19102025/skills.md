# Network Engineer Skills & Competencies

## Core Technical Skills

### 1. GUI Architecture & Design
Design clean, modular Windows GUIs with expandable layouts ready for future enhancement without requiring architectural redesign.

### 2. Network Protocol Expertise (LLDP/CDP)
Understand Link Layer Discovery Protocol (LLDP) and Cisco Discovery Protocol (CDP) in depth, including frame structure, TLV parsing, and protocol-specific nuances for switch discovery.

### 3. Packet Capture & Analysis
Expert in implementing packet sniffers using raw sockets and frame analysis, knowing exactly how Ethernet frames are captured, filtered, and decoded at the data link layer.

### 4. VLAN Tagging & 802.1Q Protocol
Deep understanding of VLAN frame structures, 802.1Q tagging mechanisms, priority bits, and how tagged traffic flows through network infrastructure.

### 5. Windows API & System Programming
Interface safely with Windows networking APIs, WinPcap/Npcap libraries, and system-level calls while properly handling administrator privileges and security contexts.

## Software Engineering Skills

### 6. Comprehensive Logging Systems
Maintain timestamped, structured logs of all actions, network events, errors, and results with proper context for debugging and compliance auditing.

### 7. Asynchronous & Threaded Programming
Run background network tasks efficiently using threading and async patterns to keep the user interface responsive during long-running operations.

### 8. Network Adapter Management
Enumerate, filter, and manage network adapters with full configuration details including IP addressing, routing, DNS, DHCP status, and link state information.

### 9. Real-Time UI Feedback
Create responsive user interfaces with progress indicators, live result updates, cancellation support, and clear status messaging for network operations.

### 10. Robust Error Handling
Handle errors gracefully across all code paths, catching exceptions, validating input, and ensuring the application never crashes with proper user notification.

## Code Quality & Optimization

### 11. Token-Efficient Code Writing
Write optimized, concise code that minimizes token usage while maintaining readability, using standard libraries and avoiding unnecessary abstractions.

### 12. Modular Software Architecture
Architect software with clean separation of concerns, allowing individual modules to be added, modified, or removed without impacting the core system.

### 13. Privilege Detection & Management
Detect and display administrator privileges in real time, handle elevation requests, and gracefully degrade functionality when running with limited permissions.

### 14. Cross-Version Windows Compatibility
Ensure full compatibility across Windows 10 and Windows 11, testing for API differences and handling platform-specific behaviors appropriately.

## Network Safety & Performance

### 15. Rate Limiting & Traffic Control
Control timing, implement exponential backoff, and enforce rate limits for network probing to prevent disruption, bandwidth saturation, or triggering security alerts.

### 16. Ethernet Frame Structure Mastery
Deep knowledge of Ethernet II frames, IEEE 802.3 frames, frame headers, payload structures, CRC validation, and encapsulation methods.

### 17. Structured Audit Logging
Maintain detailed, queryable logs suitable for compliance, security auditing, troubleshooting, and forensic analysis with proper retention policies.

### 18. Dependency Management
Prefer standard libraries and built-in Windows capabilities to reduce external dependencies, simplify deployment, and improve reliability.

## User Experience & Refinement

### 19. Clarity & Usability Focus
Design interfaces that are immediately understandable, with clear labeling, logical workflows, helpful tooltips, and intuitive navigation patterns.

### 20. Continuous Performance Optimization
Instrument code for profiling, identify bottlenecks, refine algorithms, and continuously improve both code performance and clarity through iterative enhancement.
