# Ultimate Network Tool - Quick Start

## Launching the Application

### Modern Version (Recommended)
```bash
python unt_gui_modern.py
```

### Classic Version
```bash
python unt_gui.py
```

## Important Notes

1. **Run as Administrator** - Required for packet capture and network operations
2. **Install Dependencies** - Run `pip install -r requirements.txt` first
3. **Install Npcap** - Download from https://npcap.com/ (required for packet capture)

## Features

### Modern UI Version
- 4 Tabbed interface (Overview, Switch Discovery, VLAN Probe, Settings)
- Professional color scheme with modern flat design
- Custom styled buttons with hover effects
- Card-based layout with visual hierarchy
- Clean, contemporary appearance

### Classic Version
- Simple two-panel layout
- Traditional button styling
- Side-by-side adapter info and results

## Both Versions Include
- Admin privilege detection
- Network adapter selection and detailed info display
- LLDP/CDP passive discovery
- VLAN probing with configurable ranges
- Comprehensive logging
- Real-time results display

## Logs
All operations are logged to: `logs/unt_[timestamp].log`
